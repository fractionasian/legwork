# First users — "Loop ▸" chip (2026-11-18)

Target: local build, `http://127.0.0.1:8761/index.html`, branch `claude/loop-chip-ui`
at a732788 (review fixes in). PR 2 of target-distance loops: one pin → chip →
distance → loops one at a time → Keep. Five Legwork personas, run one at a time on
Sonnet, about 40 actions each. Screenshots were kept locally only (`.playwright-mcp/`,
gitignored).

**All five reached the goal** (a loop from one pin, exported as GPX). No blockers, no
console errors from the app. Generation felt fast: about 0.45 s for 5 km and 0.9 s
for 21 km on a Mac. Both GPX files checked were valid GPX 1.1 and closed on the start.
